# PuzzlePress Studio

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated in the Interval 4 brief. Python core, optional FastAPI/uvicorn adapter,
React and TypeScript with Vite. A built frontend and API share one local origin.

## Users
Puzzle-book publishers authoring projects and reviewing generated word searches locally.

## Product Purpose
Expose the same deterministic engine used by the CLI through a visual publishing studio.

## Capabilities and Constraints
Local library, research and book planning (evidence-labelled research notes,
comparable books, audience, themes, vocabulary with provenance, puzzle allocation,
difficulty, coverage, feasibility and identity-bound approval), source overview,
visual puzzle and word-bank entry editing, shared
profile settings, book composition (matter, puzzle order, solution and numbering
policy), Python draft validation, deterministic preview, verified logical
publication-plan preview, quality review, deliberate revision-checked source
saves, saved-source interior builds, a print proof of the real PDF with
structural and modeled-KDP preflight, a photography-first full-wrap paperback
cover built from the author's own photograph and the interior's real facts, and KDP
paperback metadata with author-declared AI disclosure and confirmations, assembled
into a verified package for manual upload. No AI imagery or copy, KDP login, upload
or submission, marketplace scraping or market metrics, cloud or accounts.

## Brand Commitments
Preserve docs/images/puzzlepress-logo.png. Editorial, calm, professional, precise,
typography-forward. No fabricated publishing metrics or marketing dashboard.

## Evidence on Hand
books/composition-demo is a composed four-puzzle book. books/cover-demo is a
35-page book with a full-wrap cover over a synthetic stand-in photograph. books/publishing-demo
adds KDP metadata, leaving AI disclosure and confirmations for a person. books/garden-demo contains two real puzzle definitions. books/automotive is a legacy source fixture
with a demonstration plan for a 60-puzzle automotive book.

## Accessibility & Inclusion
Keyboard navigation, visible focus, semantic headings and grids, textual solution
coordinates, responsive desktop through mobile, status meaning beyond color.
